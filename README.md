# 💰 Python Expense Tracker

A beginner-friendly Python project to record expenses, manage spending, and track expenses by category.

## ✨ Features
- ➕ Add new expenses
- 📋 View all expenses
- 💵 Calculate total spending
- 📊 View spending by category
- 🗑️ Delete expenses
- 💾 Save data using JSON

## 🛠️ Technologies Used
- Python
- JSON
- File Handling

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python expense_tracker.py
```
